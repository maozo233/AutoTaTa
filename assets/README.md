# 资源范围

本次源码展示保留 Qt Quick 页面、自制 SVG、作者应用字标与按 OFL 提供的字体子集。原始游戏图包、识别模板、派生游戏图标和设备运行二进制不包含在展示快照中。

因此，QML 中可以看到历史界面引用的资源路径，但不能据此假定文件已随仓库提供或可以任意下载、再分发。缺失路径与摘要见 `docs/RESOURCE_MANIFEST.json`；检查方式见 `docs/SOURCE_DISTRIBUTION.md`。

`docs/media/` 提供经过检查的实际界面截图，供了解设计和交互。截图不授权提取图中第三方美术作为独立素材使用。字体和第三方许可证也不适用作者代码的非商业限制。
