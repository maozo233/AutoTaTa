# UI font subsets

Current files: `assets/fonts/ChironGoRoundTC-{500M,700B,900H}.ttf`.
Source: Chiron GoRound TC, https://github.com/chiron-fonts/chiron-go-round-tc.
The complete upstream copyright notices and SIL OFL 1.1 terms are in
`ChironGoRoundTC-OFL.txt`. Fonts are subset for the application strings; this
does not place them under the application's noncommercial source license.

Rebuild using `tools/subset_chiron.py` and legitimately obtained upstream
fonts. Full source fonts are not included in the source-showcase snapshot.
Historical versions used Resource Han Rounded CN v0.990 by Cyano Hao,
https://github.com/CyanoHao/Resource-Han-Rounded/releases/tag/v0.990.
`ResourceHanRounded-LICENSE.md` is retained for historical provenance; it
does not identify the currently shipped Chiron files as TaTa Round.
