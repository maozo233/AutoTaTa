# 可以补充的展示图

**现有 UI 截图已经可以完成仓库审核，这些补充不是发布的硬性前提。** 当前截图来自实际 0.2.36 程序的隔离界面预览：关闭设备发现与快捷键，不连接游戏，不提交自动化操作。阵容、预算和棋盘结果为配置示例。

## 优先级 1：一张 Figma 组件总览

- 建议 PNG，长边 1600～2400 像素。
- 包含基础按钮／字段／选择器、四个功能的主题，以及正常／禁用／运行中等关键状态。
- 画布上标注作者自己的设计判断，例如颜色复用、状态层级或弹窗规则。
- 避免带私人协作者名单、评论、文件访问权限、账号头像和未授权的设计内容。

用途：证明“主导设计与系统整理”的过程，补充最终软件截图无法呈现的部分。

## 优先级 2：10～20 秒无声演示

- 可选一个流程：主页进入功能 → 修改一项设置 → 显示更正或结果 → 返回。
- 使用演示状态，不暴露账号、聊天、设备序列号或桌面通知。
- 如果展示真实游戏自动化，需如实说明录制环境与成功／失败状态，不能用剪辑暗示全部可靠。
- 推荐 MP4；如做 GIF，单段 4～8 秒、宽 800～1000 像素，控制体积。

## 优先级 3：一张设计取舍对照

- 例如“只有成功／失败”与“空位／已确认／未知可修正”的反馈对照。
- 展示问题、改动、设计理由即可，不需要重新绘制全部页面。
